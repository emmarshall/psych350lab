Creating Homework Checkers with psych350lab

Overview

The psych350lab package provides interactive homework checkers that students can use in Quarto HTML documents. Students enter their answers into fill-in-the-blank boxes (fitb()) or select from dropdown menus (mcq()), and the boxes turn green for correct or red for incorrect.

These checkers rely on the webexercises and tinytable packages.

Setting Up a Quarto Document

Your Quarto HTML document needs the webexercises CSS and JS files. Add this to your YAML header:

format:
  html:
    css: [webexercises.css]
    include-after-body: [webexercises.js]

You can get these files by running webexercises::create_quarto_doc() or copying them from the webexercises package installation.

General Workflow

All checkers follow the same two-step pattern:

  1. Compute results using a *_answers() function
  2. Create checker using a create_*_checker() function
# Step 1: Compute
result <- some_answers(data, ...)

# Step 2: Create checker
create_some_checker(result, ...)

Troubleshooting

Tables Not Rendering

Ensure you have results: asis in your chunk options:

#| results: asis

webexercises Styles Missing

Check that your YAML includes the CSS and JS files:

format:
  html:
    css: [webexercises.css]
    include-after-body: [webexercises.js]

Package Not Found Errors

Install required packages:

Checker Shows Wrong Answers

Make sure you’re passing the result from the *_answers() function, not raw data:

# Wrong
create_corr_checker("RH1", vars, superman)

# Correct
result <- corr_answers(superman, "var1", "var2")
create_corr_checker("RH1", vars, result)
